# JOBMUNI — Phase 3 Agent Interaction & Governance Specification

## 1. Agent Responsibilities & Boundaries

```
[NARADA / YAMA] -> (Verified Jobs)
       |
       v
  [SARASWATI]   -> Candidate Ground Truth Evidence Bank (Zero Inventions)
       |
       +---------> [ARJUNA]   -> Skill Match & Gap Analysis
       |              |
       +---------> [KUBERA]   -> Compensation Intelligence
       |              |
       v              v
  [CHANAKYA]    -> Opportunity Prioritization & Strategy Engine
       |
       v
  [CAREER GPS]  -> Ranked Daily Actions + Explainability
       |
       v
  [HUMAN-IN-THE-LOOP APPROVAL] -> Mandatory User Sign-off (Autonomy Level 2)
```

---

## 2. Guardrails & Safety Protocols

1. **No External Communications Without Human Approval**:
   - `CHANAKYA` or `ARJUNA` can generate tailored messages, but they enter the `APPROVAL_REQUESTS` table in `PENDING` status.
   - The user must explicitly click "Approve" before any email or outreach is queued.
2. **Deterministic Evidence Attribution**:
   - Every skill match generated by `ARJUNA` must cite the specific `evidence_item_id`.
   - If an LLM or heuristic is used to format a bullet point, it must only summarize or rephrase text present in the cited evidence item.
3. **Data Freshness Contract**:
   - `CHANAKYA` will immediately downgrade any job whose YAMA verification status transitions to `INACTIVE` or `UNKNOWN`.
